# Security

Report suspected vulnerabilities privately through [GitHub security advisories](https://github.com/gritzrpc/gritz-otel/security/advisories/new), or email t.yudai92@gmail.com.

The integration omits RPC payloads, exception messages and credential metadata from spans. Configure access controls and TLS for your telemetry collector. Applications remain responsible for their authentication, authorization and data policies. CI audits gem dependencies with bundler-audit.
